# Crimenoku — privacidad y soporte

Páginas públicas de la app **Crimenoku**, servidas con GitHub Pages:

- Política de privacidad: `index.html`
- Soporte: `support.html`

Las dos están en español, inglés, alemán, francés, italiano y portugués de Brasil, los idiomas de
la app. Se generan con `python3 generar.py`.
